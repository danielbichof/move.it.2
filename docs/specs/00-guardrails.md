# Move.it 2 — Product Guardrails

O Move.it original é a base. Não recrie o produto.

## Regra principal

As novas features devem ser adicionadas SOBRE o Move.it atual para adaptá-lo ao Plano M.

**Move.it original + contexto do Plano M + novo visual**

Nunca:

**Plano M + um Timer.**

## Núcleo obrigatório

Preservar:

- Pomodoro de 35 minutos
- Iniciar / Abandonar ciclo
- Desafio ao concluir o ciclo
- Completei / Falhei
- XP por desafio concluído
- Levels e progresso
- Desafios físicos e oculares

A lógica de XP não muda para XP por minuto.

Fluxo:

**Ciclo → Desafio → XP → Progressão → Próximo ciclo**

## Plano M

O Plano M serve para dar contexto à execução.

Ele define onde a atenção deve estar:
- Estabilidade
- Crescimento
- Laboratório

O Move.it responde:

**"O que faço agora?"**

Os itens dos pilares são contexto para o ciclo, não substitutos do ciclo.

## Limites

Não transformar o Move.it em:

- task manager
- dashboard de produtividade
- habit tracker
- sistema complexo de gamificação

Evitar novas abstrações e sistemas paralelos.

## Protótipo

Usar o protótipo como referência de visual, hierarquia e experiência.

Não copiar o protótipo sacrificando o comportamento original.

Sempre adaptar o protótipo ao Move.it.

## Critério final

Se uma alteração fizer o app parecer outro produto, simplifique ou descarte.

O usuário deve continuar reconhecendo:

**foco → timer → desafio → XP → próximo ciclo**
